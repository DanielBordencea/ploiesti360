# Pozele locurilor

Pune aici pozele voastre, cu exact numele de fișier din `data/locuri.json` (câmpul `imagine`), de exemplu:

- muzeul-ceasului-ploiesti.jpg
- halele-centrale-ploiesti.jpg
- palatul-culturii-ploiesti.jpg

Recomandat: JPG, raport 4:3, lățime 1200 px, sub 250 KB. Până apare fișierul, site-ul afișează automat un placeholder cu numele locului.
După ce adaugi poze, rulează `node build.js`.
